# Internacionalização (i18n)

O GitPR detecta automaticamente o idioma do seu sistema e exibe todas as mensagens no seu idioma nativo. O sistema i18n é inspirado no **helper `__()` do Laravel**.

---

## Como Funciona

1. **Detecção automática:** Na primeira execução, o GitPR detecta o idioma do seu SO e salva em `~/.gitpr/.env` como `GITPR_LANG`
2. **Pacotes de tradução:** Os arquivos de idioma são baixados automaticamente do repositório oficial para `~/.gitpr/langs/`
3. **Fallback para inglês:** Se uma chave de tradução estiver faltando, o texto em inglês é exibido como fallback
4. **Substituição por execução:** Use `--lang <código>` para forçar um idioma em um único comando sem alterar sua configuração

---

## Idiomas Suportados

| Código | Idioma | Status |
| --- | --- | --- |
| `en` | Inglês | Completo |
| `pt_br` | Português (Brasil) | Completo |
| `pt_pt` | Português (Portugal) | Completo |
| `fr` | Francês | Completo |
| `es` | Espanhol | Completo |

---

## Uso

### Definir Idioma Padrão

```bash
# Em ~/.gitpr/.env
GITPR_LANG=pt_br
```

### Substituir para Um Comando

```bash
gitpr -c --lang en        # Gerar mensagem de commit em inglês
gitpr -r --lang pt_br     # Code review em português do Brasil
gitpr -ch --lang fr       # Interface do chat em francês
```

## API para Desenvolvedores

O GitPR expõe um módulo i18n para contribuidores:

```python
from src.i18n import __

# Tradução simples
print(__("Seu texto aqui"))

# Com placeholders nomeados
print(__("Baixando {file}...", file="template.md"))
print(__("Encontrados {count} problemas em {path}", count=5, path="src/main.py"))
```

---

## Adicionando um Novo Idioma

1. Crie um arquivo JSON em `~/.gitpr/langs/` usando o código do idioma (ex: `de.json` para alemão)
2. Copie a estrutura de um arquivo de idioma existente (`en.json` ou `pt_br.json`)
3. Traduza todos os valores de string — mantenha as chaves JSON idênticas
4. Envie um PR para o [repositório GitPR](https://github.com/natafiuza/gitpr)

### Exemplo de Entrada de Tradução

```json
{
    "welcome": "Bem-vindo ao GitPR CLI!",
    "first_run_detected": "Primeira execução detectada! Vamos configurar o GitPR CLI.",
    "enter_api_key": "Digite sua GEMINI_API_KEY:",
    "commit_generated": "Mensagem de commit gerada com sucesso.",
    "linter_violation": "🚨 Violação em {file_name}:{line_number}"
}
```

Todas as strings voltadas ao usuário — saída do CLI, menus de ajuda, mensagens do linter, interface TUI — usam este sistema de tradução.
