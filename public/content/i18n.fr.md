# Internationalisation (i18n)

GitPR détecte automatiquement la langue de votre système et affiche tous les messages dans votre langue maternelle. Le système i18n est inspiré du **helper `__()` de Laravel**.

---

## Comment Ça Marche

1. **Détection automatique :** Lors de la première exécution, GitPR détecte la langue de votre OS et l'enregistre dans `~/.gitpr/.env` comme `GITPR_LANG`
2. **Packs de traduction :** Les fichiers de langue sont téléchargés automatiquement depuis le dépôt officiel vers `~/.gitpr/langs/`
3. **Fallback anglais :** Si une clé de traduction est manquante, le texte anglais est affiché comme fallback
4. **Remplacement par exécution :** Utilisez `--lang <code>` pour forcer une langue pour une seule commande sans modifier votre configuration

---

## Langues Supportées

| Code | Langue | Statut |
| --- | --- | --- |
| `en` | Anglais | Complet |
| `pt_br` | Portugais (Brésil) | Complet |
| `pt_pt` | Portugais (Portugal) | Complet |
| `fr` | Français | Complet |
| `es` | Espagnol | Complet |

---

## Utilisation

### Définir la Langue par Défaut

```bash
# Dans ~/.gitpr/.env
GITPR_LANG=fr
```

### Remplacer pour une Commande

```bash
gitpr -c --lang en        # Générer un message de commit en anglais
gitpr -r --lang fr        # Code review en français
gitpr -ch --lang pt_br    # Interface du chat en portugais brésilien
```

## API pour Développeurs

GitPR expose un module i18n pour les contributeurs :

```python
from src.i18n import __

# Traduction simple
print(__("Votre texte ici"))

# Avec des placeholders nommés
print(__("Téléchargement de {file}...", file="template.md"))
print(__("{count} problèmes trouvés dans {path}", count=5, path="src/main.py"))
```

## Ajouter une Nouvelle Langue

1. Créez un fichier JSON dans `~/.gitpr/langs/` en utilisant le code de langue (ex : `de.json` pour l'allemand)
2. Copiez la structure d'un fichier de langue existant (`en.json` ou `fr.json`)
3. Traduisez toutes les valeurs de chaîne — gardez les clés JSON identiques
4. Soumettez une PR au [dépôt GitPR](https://github.com/natafiuza/gitpr)

### Exemple d'Entrée de Traduction

```json
{
    "welcome": "Bienvenue dans GitPR CLI !",
    "first_run_detected": "Première exécution détectée ! Configurons GitPR CLI.",
    "enter_api_key": "Entrez votre GEMINI_API_KEY :",
    "commit_generated": "Message de commit généré avec succès.",
    "linter_violation": "🚨 Violation dans {file_name}:{line_number}"
}
```

Toutes les chaînes destinées à l'utilisateur — sortie CLI, menus d'aide, messages du linter, interface TUI — utilisent ce système de traduction.
