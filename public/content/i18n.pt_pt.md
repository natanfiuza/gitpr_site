# Internacionalização (i18n)

O GitPR deteta automaticamente o idioma do seu sistema e exibe todas as mensagens no seu idioma nativo. O sistema i18n é inspirado no **helper `__()` do Laravel**.

---

## Como Funciona

1. **Deteção automática:** Na primeira execução, o GitPR deteta o idioma do seu SO e guarda em `~/.gitpr/.env` como `GITPR_LANG`
2. **Pacotes de tradução:** Os ficheiros de idioma são transferidos automaticamente do repositório oficial para `~/.gitpr/langs/`
3. **Fallback para inglês:** Se uma chave de tradução estiver em falta, o texto em inglês é exibido como fallback
4. **Substituição por execução:** Use `--lang <código>` para forçar um idioma num único comando sem alterar a sua configuração

---

## Idiomas Suportados

| Código | Idioma | Estado |
| --- | --- | --- |
| `en` | Inglês | Completo |
| `pt_br` | Português (Brasil) | Completo |
| `pt_pt` | Português (Portugal) | Completo |
| `fr` | Francês | Completo |
| `es` | Espanhol | Completo |

---

## Utilização

### Definir Idioma Padrão

```bash
# Em ~/.gitpr/.env
GITPR_LANG=pt_pt
```

### Substituir para Um Comando

```bash
gitpr -c --lang en        # Gerar mensagem de commit em inglês
gitpr -r --lang pt_pt     # Code review em português de Portugal
gitpr -ch --lang fr       # Interface do chat em francês
```

## API para Programadores

O GitPR expõe um módulo i18n para contribuidores:

```python
from src.i18n import __

# Tradução simples
print(__("O seu texto aqui"))

# Com placeholders nomeados
print(__("A transferir {file}...", file="template.md"))
print(__("Encontrados {count} problemas em {path}", count=5, path="src/main.py"))
```

## Adicionando um Novo Idioma

1. Crie um ficheiro JSON em `~/.gitpr/langs/` usando o código do idioma (ex: `de.json` para alemão)
2. Copie a estrutura de um ficheiro de idioma existente (`en.json` ou `pt_pt.json`)
3. Traduza todos os valores de string — mantenha as chaves JSON idênticas
4. Envie um PR para o [repositório GitPR](https://github.com/natafiuza/gitpr)

### Exemplo de Entrada de Tradução

```json
{
    "welcome": "Bem-vindo ao GitPR CLI!",
    "first_run_detected": "Primeira execução detetada! Vamos configurar o GitPR CLI.",
    "enter_api_key": "Introduza a sua GEMINI_API_KEY:",
    "commit_generated": "Mensagem de commit gerada com sucesso.",
    "linter_violation": "🚨 Violação em {file_name}:{line_number}"
}
```

Todas as strings voltadas ao utilizador — saída do CLI, menus de ajuda, mensagens do linter, interface TUI — usam este sistema de tradução.
