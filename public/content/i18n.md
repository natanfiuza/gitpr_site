# Internationalization (i18n)

GitPR automatically detects your system language and displays all messages in your native language. The i18n system is inspired by **Laravel's `__()` helper**.

---

## How It Works

1. **Auto-detection:** On first run, GitPR detects your OS language and saves it to `~/.gitpr/.env` as `GITPR_LANG`
2. **Translation packs:** Language files are downloaded automatically from the official repository to `~/.gitpr/langs/`
3. **English fallback:** If a translation key is missing, the English text is displayed as fallback
4. **Per-execution override:** Use `--lang <code>` to force a language for a single command without changing your config

---

## Supported Languages

| Code | Language | Status |
| --- | --- | --- |
| `en` | English | Complete |
| `pt_br` | Portuguese (Brazil) | Complete |
| `pt_pt` | Portuguese (Portugal) | Complete |
| `fr` | French | Complete |
| `es` | Spanish | Complete |

---

## Usage

### Set Default Language

```bash
# In ~/.gitpr/.env
GITPR_LANG=pt_br
```

### Override for One Command

```bash
gitpr -c --lang en        # Generate commit message in English
gitpr -r --lang pt_br     # Code review in Brazilian Portuguese
gitpr -ch --lang fr       # Chat interface in French
```

---

## Developer API

GitPR exposes an i18n module for contributors:

```python
from src.i18n import __

# Simple translation
print(__("Your text here"))

# With named placeholders
print(__("Downloading {file}...", file="template.md"))
print(__("Found {count} issues in {path}", count=5, path="src/main.py"))
```

---

## Adding a New Language

1. Create a JSON file in `~/.gitpr/langs/` using the language code (e.g., `de.json` for German)
2. Copy the structure from an existing language file (`en.json` or `pt_br.json`)
3. Translate all string values — keep the JSON keys identical
4. Submit a PR to the [GitPR repository](https://github.com/natafiuza/gitpr)

### Example Translation Entry

```json
{
    "welcome": "Welcome to GitPR CLI!",
    "first_run_detected": "First run detected! Let's configure GitPR CLI.",
    "enter_api_key": "Enter your GEMINI_API_KEY:",
    "commit_generated": "Commit message generated successfully.",
    "linter_violation": "🚨 Violation in {file_name}:{line_number}"
}
```

All user-facing strings — CLI output, help menus, linter messages, TUI interface — use this translation system.
