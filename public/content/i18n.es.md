# Internacionalización (i18n)

GitPR detecta automáticamente el idioma de tu sistema y muestra todos los mensajes en tu idioma nativo. El sistema i18n está inspirado en el **helper `__()` de Laravel**.

---

## Cómo Funciona

1. **Detección automática:** En la primera ejecución, GitPR detecta el idioma de tu SO y lo guarda en `~/.gitpr/.env` como `GITPR_LANG`
2. **Paquetes de traducción:** Los archivos de idioma se descargan automáticamente del repositorio oficial a `~/.gitpr/langs/`
3. **Fallback al inglés:** Si falta una clave de traducción, el texto en inglés se muestra como fallback
4. **Sobrescritura por ejecución:** Usa `--lang <código>` para forzar un idioma en un solo comando sin cambiar tu configuración

---

## Idiomas Soportados

| Código | Idioma | Estado |
| --- | --- | --- |
| `en` | Inglés | Completo |
| `pt_br` | Portugués (Brasil) | Completo |
| `pt_pt` | Portugués (Portugal) | Completo |
| `fr` | Francés | Completo |
| `es` | Español | Completo |

---

## Uso

### Definir Idioma por Defecto

```bash
# En ~/.gitpr/.env
GITPR_LANG=es
```

### Sobrescribir para Un Comando

```bash
gitpr -c --lang en        # Generar mensaje de commit en inglés
gitpr -r --lang es        # Code review en español
gitpr -ch --lang pt_br    # Interfaz del chat en portugués brasileño
```

## API para Desarrolladores

GitPR expone un módulo i18n para contribuidores:

```python
from src.i18n import __

# Traducción simple
print(__("Tu texto aquí"))

# Con placeholders nombrados
print(__("Descargando {file}...", file="template.md"))
print(__("Encontrados {count} problemas en {path}", count=5, path="src/main.py"))
```

---

## Añadiendo un Nuevo Idioma

1. Crea un archivo JSON en `~/.gitpr/langs/` usando el código de idioma (ej: `de.json` para alemán)
2. Copia la estructura de un archivo de idioma existente (`en.json` o `es.json`)
3. Traduce todos los valores de cadena — mantén las claves JSON idénticas
4. Envía un PR al [repositorio GitPR](https://github.com/natafiuza/gitpr)

### Ejemplo de Entrada de Traducción

```json
{
    "welcome": "¡Bienvenido a GitPR CLI!",
    "first_run_detected": "¡Primera ejecución detectada! Vamos a configurar GitPR CLI.",
    "enter_api_key": "Ingresa tu GEMINI_API_KEY:",
    "commit_generated": "Mensaje de commit generado exitosamente.",
    "linter_violation": "🚨 Violación en {file_name}:{line_number}"
}
```

Todas las cadenas orientadas al usuario — salida CLI, menús de ayuda, mensajes del linter, interfaz TUI — usan este sistema de traducción.
